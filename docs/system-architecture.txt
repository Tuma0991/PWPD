## How It Works (Simple)

The **Protected Person** wears a small ESP32 device with a motion sensor and GPS. The device continuously sends location and movement data to **Firebase Cloud**. If the person falls or presses the SOS button, an emergency alert fires instantly.

The **Guardian (Parent)** opens the Flutter mobile app to see a live dashboard — where the person is on a map, whether they're moving, and whether a fall or emergency has been detected. The guardian can set up safe zones (geofences) and gets notified if the wearer leaves or enters them. They can also manage a list of **Emergency Contacts** to call with one tap.

Everything flows through **Firebase** — the device writes data, the app reads it in real time, and persistent records (contacts, geofences, alert history) are stored for later reference.

## Key Components

| Component | What It Does |
|-----------|-------------|
| **ESP32 Wearable Device** | Reads accelerometer + GPS, detects falls, checks geofences, sends data to Firebase via WiFi. Has a physical SOS button and status LED. |
| **Flutter Mobile App** | The guardian's app. Shows live dashboard, GPS map, fall detection status, alert history. Manages contacts and geofences. Provisions the device over BLE. |
| **Firebase Cloud** | Stores and syncs everything. Real-time Database handles live sensor/emergency streams. Firestore handles persistent data (users, contacts, geofences, alerts). |
| **Protected Person** | The wearer. Their movement generates data; they can press SOS for help. |
| **Guardian / Parent** | The caregiver. Monitors the protected person, responds to emergencies, configures the system. |
| **Emergency Contacts** | People the guardian can call with one tap during an emergency. Stored as contacts in the app. |

## Separation of Concerns

| Concern | Handled By |
|---------|-----------|
| Sensing movement & location | ESP32 (MPU6050 + GT-U8 GPS) |
| Detecting falls | ESP32 (on-device, < 2.5g threshold) |
| Real-time data sync | Firebase Realtime Database |
| Persistent storage | Firebase Cloud Firestore |
| User authentication | Firebase Auth (email/password) |
| Live monitoring UI | Flutter app (6-tab dashboard) |
| Geofence management | Flutter app (create) + ESP32 (enforce) |
| Emergency response | Flutter app (notify + tap-to-call) |
| Device setup | Flutter app ↔ ESP32 via Bluetooth (BLE) |
